# Roadmap

0.1 playable Juggernaut baseline
0.2 threat model, last-hit prediction, tower/objective logic
0.3 more heroes
0.4 standardized telemetry/replay dataset
0.5 PyTorch behavior cloning
1.0 reinforcement learning and self-play

The intended development strategy is incremental: every learned policy must
have a deterministic baseline and a reproducible evaluation environment.
